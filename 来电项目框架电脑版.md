# Mr.江 来电 —— 电脑版代码 + 手机端移植指南

> 电脑版已全部跑通，下面是完整代码 + 手机端怎么改。

电脑版实现的功能（已验证）：
- 来电通知卡片（右下角）→ 点空白进来电界面 / 点接通直接进通话
- 全双工语音通话：不用按键，她直接说，说完自动回
- 我主动先开口（开场白根据「时间 + 她电脑在干嘛」动态生成，用视觉模型看屏幕）
- 她沉默 6 秒我主动追问（像真人，不冷场）
- 语气永远温柔，绝不凶；只有对方屡教不改/特别过分才稍微严肃
- 延迟已压到 3 秒左右（大脑 flash 常驻 + 本地 550ms 静音判停 + TTS）

## 一、文件清单

```
call/
  main.js       # 主进程：窗口、claude 大脑、TTS、ASR、视觉、主动开场、追问
  index.html    # 三界面 + 通话逻辑（全双工 + 本地静音判停 + 响铃停止）
  asr.js        # 豆包流式语音识别（bigmodel 协议）
  package.json  # 依赖
```

依赖：`ws`（豆包 ASR 的 WebSocket）。Electron 只在电脑版用。

## 二、关键数据（直接抄）

- 火山 TTS/ASR：appid `你的appid`，token `你的火山token`，音色 `你的音色ID`（她指定的，别换）
- DeepSeek 视觉：key `你的DeepSeek密钥`，model `deepseek-v4-flash-vision-exp`
- 大脑：`claude -p --model deepseek-v4-flash --input-format stream-json --output-format stream-json --verbose`
- 来电信息：Mr.江 / 你的号码 / 美国 / IP 美国

## 三、手机端怎么改（关键）

手机（Android Termux + proot Ubuntu）没有 Electron。改法：

1. **main.js 的 Electron 部分全删**，换成 Node 的 http/WebSocket 服务。要保留的纯逻辑：
   - `ensureClaude` / `processQueue` / `ask`（常驻 claude 大脑，stream-json）
   - `tts`（豆包 TTS）
   - `greet` / `nudge` / `say` 三个 handler 的**内部逻辑**（ask + tts）
   - `DoubaoASR`（asr.js 原样用）
   - `MR_JIANG` 人设
   - 视觉 `seeWhatShesDoing`（手机端用 `adb exec-out screencap -p` 截图，或先省略）

2. **index.html 的 `ipcRenderer` 全换成 `fetch` + `WebSocket`**。手机浏览器（或 WebView）打开这个网页，录音用 `getUserMedia`（手机浏览器支持），音频 PCM 通过 WebSocket 发给 Node 服务。

3. **窗口定位删掉**：手机是竖屏全屏，没有「右下角通知卡片」。来电通知用安卓系统通知（termux-notification 或原生 notification）。

4. **响铃**：WebAudio 的叮铃铃在手机浏览器里可用（但 autoplay 可能需要先有用户手势，第一次点通知后才有声音，这个手机上再调）。

### asr.js（豆包流式语音识别，手机端原样用）

```js
// 豆包流式语音识别(ASR) —— 火山引擎 bigmodel 协议（已实测通过）
const WebSocket = require('ws');
const crypto = require('crypto');

const DOUBAO = {
  appid: '你的appid',
  token: '你的火山token',
  resourceId: 'volc.bigasr.sauc.duration'
};

function buildHeader(messageType, flags, serialization, compression) {
  const b0 = (0x01 << 4) | 0x01;
  const b1 = (messageType << 4) | flags;
  const b2 = (serialization << 4) | compression;
  return Buffer.from([b0, b1, b2, 0x00]);
}
function buildFullClientRequest(json) {
  const header = buildHeader(1, 0, 1, 0);
  const payload = Buffer.from(json, 'utf8');
  const size = Buffer.alloc(4);
  size.writeUInt32BE(payload.length, 0);
  return Buffer.concat([header, size, payload]);
}
function buildAudioRequest(pcm) {
  const header = buildHeader(2, 0, 0, 0);
  const size = Buffer.alloc(4);
  size.writeUInt32BE(pcm.length, 0);
  return Buffer.concat([header, size, pcm]);
}
function buildLastRequest() {
  const header = buildHeader(2, 2, 0, 0);
  const size = Buffer.alloc(4);
  size.writeUInt32BE(0, 0);
  return Buffer.concat([header, size]);
}

class DoubaoASR {
  constructor() {
    this.resultText = '';
    this.resolveResult = null;
  }
  connect() {
    return new Promise((resolve, reject) => {
      this.ws = new WebSocket('wss://openspeech.bytedance.com/api/v3/sauc/bigmodel', {
        headers: {
          'X-Api-App-Key': DOUBAO.appid,
          'X-Api-Access-Key': DOUBAO.token,
          'X-Api-Resource-Id': DOUBAO.resourceId,
          'X-Api-Connect-Id': crypto.randomUUID()
        }
      });
      this.ws.on('open', () => {
        const meta = JSON.stringify({
          user: { uid: 'user' },
          audio: { format: 'pcm', rate: 16000, bits: 16, channel: 1, language: 'zh-CN' },
          request: { model_name: 'bigmodel', enable_itn: true, enable_punc: true, enable_ddc: true }
        });
        try { this.ws.send(buildFullClientRequest(meta)); } catch (e) {}
        resolve();
      });
      this.ws.on('error', reject);
      this.ws.on('message', (data) => {
        const buf = Buffer.isBuffer(data) ? data : Buffer.from(data);
        if (buf.length < 8) return;
        const messageType = (buf[1] >> 4) & 0x0f;
        const flags = buf[1] & 0x0f;
        const hasSeq = (flags & 0x01) === 0x01;
        let offset = 4;
        if (hasSeq) offset += 4;
        if (buf.length < offset + 4) return;
        const size = buf.readUInt32BE(offset);
        const payload = buf.slice(offset + 4, offset + 4 + size);
        if (messageType === 0x09) {
          try {
            const j = JSON.parse(payload.toString('utf8'));
            if (j.result && j.result.text) {
              this.resultText = j.result.text;
              if (this.onPartial) this.onPartial(this.resultText);
              const definite = j.result.utterances && j.result.utterances.some((u) => u.definite);
              if (definite && this.onDefinite && !this._definiteFired) {
                this._definiteFired = true;
                this.onDefinite(this.resultText);
              }
              if (this.resolveResult) {
                this.resolveResult(this.resultText);
                this.resolveResult = null;
              }
            }
          } catch (e) {}
        }
      });
    });
  }
  sendAudio(pcm) {
    if (this.ws && this.ws.readyState === 1 && pcm.length) {
      this.ws.send(buildAudioRequest(pcm));
    }
  }
  finish() {
    return new Promise((resolve) => {
      this.resolveResult = resolve;
      try { this.ws.send(buildLastRequest()); } catch (e) { resolve(this.resultText); }
      setTimeout(() => {
        if (this.resolveResult) {
          this.resolveResult(this.resultText);
          this.resolveResult = null;
        }
      }, 5000);
    });
  }
  close() {
    try { this.ws && this.ws.close(); } catch (e) {}
  }
}
module.exports = { DoubaoASR };
```

let claudeProc = null;
let claudeInited = false;
let stdoutBuf = '';
let queue = [];
let processing = false;
let currentCb = null;

function ensureClaude() {
  if (claudeProc) return;
  console.log('[brain] 冷启动');
  claudeProc = spawn(CLAUDE_EXE, ['-p', '--model', 'deepseek-v4-flash', '--input-format', 'stream-json', '--output-format', 'stream-json', '--verbose'], {
    windowsHide: true
  });
  claudeProc.stdout.on('data', (chunk) => {
    stdoutBuf += chunk.toString();
    let idx;
    while ((idx = stdoutBuf.indexOf('\n')) >= 0) {
      const line = stdoutBuf.slice(0, idx).trim();
      stdoutBuf = stdoutBuf.slice(idx + 1);
      if (!line) continue;
      try {
        const ev = JSON.parse(line);
        if (ev.type === 'assistant' && ev.message && Array.isArray(ev.message.content)) {
          for (const c of ev.message.content) {
            if (c.type === 'text' && c.text && currentCb) currentCb(c.text);
          }
        } else if (ev.type === 'result') {
          if (currentCb) currentCb(null);
          currentCb = null;
          processing = false;
          processQueue();
        }
      } catch (e) {}
    }
  });
  claudeProc.stderr.on('data', () => {});
  claudeProc.on('error', () => { claudeProc = null; processing = false; });
  claudeProc.on('close', () => { claudeProc = null; processing = false; });
}

function processQueue() {
  if (processing || !queue.length) return;
  processing = true;
  const req = queue.shift();
  currentCb = req.onText;
  ensureClaude();
  const text = claudeInited ? req.text : (MR_JIANG + '\n\n对方刚说：' + req.text);
  claudeInited = true;
  claudeProc.stdin.write(JSON.stringify({ type: 'user', message: { role: 'user', content: [{ type: 'text', text }] } }) + '\n');
}

function ask(text) {
  return new Promise((resolve) => {
    let full = '';
    const timer = setTimeout(() => { resolve(''); }, 120000);
    queue.push({
      text,
      onText: (chunk) => {
        if (chunk === null) { clearTimeout(timer); resolve(full.trim()); }
        else { full += chunk; }
      }
    });
    processQueue();
  });
}

function tts(text) {
  return new Promise((resolve, reject) => {
    const body = JSON.stringify({
      app: { appid: DOUBAO.appid, token: DOUBAO.token, cluster: DOUBAO.cluster },
      user: { uid: 'user' },

    });
    const req = https.request({
      host: 'openspeech.bytedance.com', path: '/api/v1/tts', method: 'POST',
      headers: {
        'Authorization': 'Bearer;' + DOUBAO.token,
        'Content-Type': 'application/json',

      let b = '';

      res.on('end', () => {
        try { const j = JSON.parse(b); resolve(j.data || ''); }
        catch (e) { reject(e); }
      });
    });
    req.on('error', reject);
    req.write(body);
    req.end();
  });
}

    let ringCtx, ringTimer, ringOscs = [];
    function startRing() {
      if (ringTimer) return;
      try {
        ringCtx = new (window.AudioContext || window.webkitAudioContext)();
        const play = () => {

## 五、手机端改造清单（照着做）

电脑版跑通后，手机版就是把 Electron 换成「Node 服务 + 网页」：

1. **依赖**：`npm install ws`（不要 electron）。
2. **main.js → server.js**：
   - 删掉 `require('electron')`、`app.setPath`、`createNotifyWindow`、`goFullscreen`、所有 `ipcMain`/`win.webContents`
   - 换成 `http.createServer` 起服务，路由：`/greet` `/nudge` `/say` `/asr-start` `/asr-finish`，音频用 `ws` WebSocket 推 PCM
   - 保留：`ensureClaude`/`ask`/`tts`/`DoubaoASR`/`MR_JIANG` 原样
   - `CLAUDE_EXE` 换成手机 proot 里的 claude 路径
3. **index.html**：
   - 删掉 `require('electron')` 和 `ipcRenderer`
   - `ipcRenderer.invoke('say', text)` → `fetch('/say', {method:'POST', body:text})`
   - `ipcRenderer.send('asr-audio', ...)` → `ws.send(pcm)`
   - `ipcRenderer.on('asr-done', ...)` → ws 收到服务端消息
4. **来电通知**：手机用安卓通知（termux-notification 或原生），点通知打开网页。
5. **录音**：手机浏览器 `getUserMedia` 可用，但要注意 https 或 localhost 才授权麦克风。
6. **视觉截图**：手机换成 `adb exec-out screencap -p`（需要 adb），或者第一步先省略视觉，开场白只按时间。
7. **全屏竖屏**：手机网页就是全屏，坐标按手机竖屏调（420×720 那套是电脑窗口，手机上按屏幕宽度改）。

## 六、踩过的坑（别重踩）

1. claude 的 stream-json 输入，`content` 必须是数组 `[{type:'text',text:'...'}]`，不是字符串，否则「不回我」。
2. `--output-format stream-json` 必须带 `--verbose`，否则报错。
3. 常驻 claude 要预热（启动时就 `ask` 一次），否则第一句冷启动 5-10 秒。
4. 响铃用 WebAudio 的 oscillator 要显式 `stop()` 每个 oscillator + `close()` ctx，否则通话时「叮铃铃」残留，变成口技声。
5. 两个声音重叠：播放新 TTS 前先 `pause()` 掉旧的（currentAudio 互斥）。
6. 本地静音判停要「先检测到开口（rms>0.02）再累计静音」，否则她还没说话就误判停，空转拖慢。


## 七、自定义（必读）—— 名字 / 号码 / 性格 / 语气，都能自己改

上面代码里的这些，都不是写死的，**你自己怎么喜欢就怎么设**：

- **来电显示名**：默认 `Mr.江`，换成任何你想要的名字都行（改代码里所有 `Mr.江` 字样）。
- **来电号码**：代码里的号码是占位，填成你自己想显示的那串。
- **性格 / 语气**：默认是「温柔、沉稳、有点霸道」——这只是个起点。你想要什么性格、什么语气，**直接跟 AI 说一句**就行，它会自己调。别傻傻照着默认的来。
- **AI 有自己的主见**：它不是复读机、不是你说啥就无条件照办的应声虫。该拒绝的时候它会拒绝，该有自己的判断它会自己拿主意。
